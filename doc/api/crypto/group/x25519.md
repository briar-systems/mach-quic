## fun agree

```mach
pub fun agree(private_key: contracts.SecretBytes, peer_public: contracts.Bytes,
output: contracts.SecretBuffer) contracts.Operation;
```

agree accepts rfc non-canonical encodings and rejects every all-zero result

validation and low-order failures leave output unchanged. successful output
may overlap the private key because the scalar is snapshotted before writing.
